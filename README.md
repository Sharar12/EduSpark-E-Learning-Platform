# EduSpark E-Learning Platform

EduSpark is an e-learning platform project focused on presenting educational content through a web application.

## Overview

The project explores course and learning-content presentation and provides a foundation for building learner-facing education workflows.

## Goals

- Organize and present learning content
- Explore course/learner workflows
- Practice full-stack web application development
- Provide a base for future authentication, progress tracking, payments, and administration

## Technology

This repository is a compact project. The framework versions and dependencies used by the current codebase are the source of truth.

## Getting Started

Clone the repository, install the dependencies required by the project files, and run it using the scripts/configuration included in the repository.

## Status

Learning/project repository and may evolve as additional platform features are added.
